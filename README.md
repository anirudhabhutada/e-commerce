## 🏛️ Brand Essence & Philately
**Kalaa Culture** transforms centuries of sacred iconography, Maharashtrian cultural pride, and Mumbai Ganesh Utsav memories into timeless, collectible design artifacts. 

Inspired by vintage postal stamps—classic symbols of communication, heritage, and value—Kalaa Culture crafts collectible acrylic stamp fridge magnets with authentic Devanagari typography, postal cancellation watermarks, and high-strength neodymium magnetic cores.

### Honoring Mumbai's Historic Mandals:
* **मुंबईचा राजा (Mumbai Cha Raja)** — Ganesh Galli (The Hand of Love Edition)
* **चिंचपोकळीचा चिंतामणी (Chinchpoklicha Chintamani)** — 105 Years of Devotion (Sudarshan Mudra)
* **परळचा राजा (Parelcha Raja)** — Royal Feta Profile & Sunset Horizon Editions
* **लालबागचा राजा (Lalbaugcha Raja)** — Navsacha Ganpati (Golden Throne & Sacred Eyes)
* **काळचौकीचा महागणपती (Kalachowki Cha Mahaganpati)** — The Hand of Hope Edition
* **मुंबई गणपती पंचरत्न भेटपेटी** — Limited 5-Piece Complete Mandal Box Set

## ✨ Features

- **Luxury Cultural Aesthetic**: Vermilion Crimson (`#94171B`), Mandir Gold (`#D4AF37`), Sandstone parchment, and deep charcoal styling.
- **Museum-Grade Visuals**: High-resolution studio photography and outdoor Mumbai sky captures for every deity keepsake.
- **Dynamic E-Commerce Architecture**:
  - Full product catalog with real-time category filtering (Stamp Magnets, Box Sets, Heritage Keepsakes, Die-Cut Stickers).
  - Product detail pages with zoomable galleries, specification tables, and related collections.
  - Interactive cart drawer with free shipping progression bar and coupon system (`GANPATI10`).
  - Multi-step checkout with instant WhatsApp direct order fallback (`+91 78750 05963`).
  - Search modal with instant keyword matching and direct navigation.
- **Accessibility & SEO**: Schema.org JSON-LD microdata, semantic HTML5, keyboard navigation, and Open Graph tags.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 7
- **Icons**: Lucide React
- **Typography**: Cormorant Garamond, Plus Jakarta Sans, Rozha One, Tiro Devanagari Marathi
- **State Management**: React Context API with LocalStorage persistence

## 🚀 Getting Started

### 1. Clone & Install
```bash
git clone https://github.com/<your-username>/kalaa-culture.git
cd kalaa-culture
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### 3. Production Build
```bash
npm run build
npm run preview
```
